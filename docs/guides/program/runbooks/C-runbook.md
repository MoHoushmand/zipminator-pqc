## Tauri desktop signing
1. Install Developer ID Application cert (verify: `security find-identity -v -p codesigning`).
2. Set `signingIdentity` in `browser/src-tauri/tauri.conf.json`; export APPLE_ID/APPLE_PASSWORD/APPLE_TEAM_ID.
3. `rustup target add x86_64-apple-darwin`; `tauri build --target universal-apple-darwin`; `xcrun stapler staple`.
