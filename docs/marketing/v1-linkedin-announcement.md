1. Quantum Vault and Self-Destruct Storage

Implements NIST FIPS 203 (ML-KEM-768) for key encapsulation and FIPS 204 (ML-DSA-65) for signatures. Verified against NIST Known Answer Test vectors. Built on a single from-scratch Rust core exposed to Python and Flutter.

Q-day is not a hypothetical. Harvest-now-decrypt-later is already policy for state-level adversaries. Every packet you ship today is a bet that RSA-2048 holds. Zipminator replaces that bet.

Not FIPS 140-3 certified yet; CMVP submission planned. No classical-only crypto on the user-data path.
