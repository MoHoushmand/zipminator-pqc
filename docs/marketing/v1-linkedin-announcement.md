Zipminator v1.0.0 is live.

Nine pillars of post-quantum cryptography on a single codebase, built on NIST's finalized PQC standards:

1. Quantum Vault + Self-Destruct Storage
2. PQC Messenger (ML-KEM-768 + ML-DSA-65)
3. Quantum VoIP + Video
4. Q-VPN (PQ-WireGuard)
5. 10-Level Anonymization Suite
6. Q-AI PQC AI Assistant
7. Quantum-Secure Email
8. ZipBrowser (PQC AI Browser)
9. Q-Mesh (Quantum-Secured WiFi Sensing)

Crypto core: Rust, 550 tests passing, PyO3 bindings for Python, FFI bridge for Flutter. Implements NIST FIPS 203 (ML-KEM-768) and NIST FIPS 204 (ML-DSA-65). True quantum entropy from IBM Quantum hardware (156 qubits).

DORA-aligned key lifecycle logging. Hybrid classical+PQC mode during migration.

Ships across iOS (TestFlight external), Android, macOS, Linux, Windows, and a Next.js 16 web dashboard.
